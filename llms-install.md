# Install ThriveDesk MCP

ThriveDesk MCP is a hosted remote server. Do not clone or build anything.

1. Add a remote MCP server named "thrivedesk" with URL https://mcp.thrivedesk.com and transport streamable HTTP.
2. Start the connection. A browser window opens on ThriveDesk. The user signs in, picks a workspace and an access preset, and selects Authorize.
3. Test with: "List my ThriveDesk inboxes." Real inbox names mean it works.

Requires a ThriveDesk Standard or Unlimited plan.
